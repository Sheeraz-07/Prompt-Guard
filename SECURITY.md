# Security Policy

## Supported versions

Only the latest version on the `main` branch is actively maintained.

## Reporting a vulnerability

Please do not open a public issue for a vulnerability. Use GitHub's private security advisory flow for this repository, or contact the maintainer privately through the GitHub profile.

Include a description, affected files or versions, reproduction steps, and the potential impact. Remove or replace all real secrets before sending examples.

PromptGuard is a local extension, so reports involving secret detection, restoration mappings, browser permissions, content isolation, or accidental network access are especially important.
